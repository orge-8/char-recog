# 内容类型轴：一个尚未分离的混淆

> 状态：**待测量**。在实验结果出来之前，报告里任何「画法导致召回差异」的说法都不成立。

## 1. 问题

0.5.11 起，四档 `flat / paint / photo / composite` 被描述为「媒材单轴」，并用下面这个数字支撑：

> 平涂 Q 版贴纸召回 79–91%，厚涂同人插画只有 2%。

这个对比是**跨语料**的，不是同一批数据内的对比：

| 语料 | 内容 | 是否进训练集 |
|---|---|---|
| `lty` / `lty1` / `洛天依` / `洛天依1` / `洛天依2`（264 张） | 71% 平涂 Q 版贴纸、25% 梗图、3% 官方三视图 | 是 |
| `洛天依4`（151 张） | 同人插画（厚涂/柔光上色） | **否** |

所以「厚涂 2%」是**分布外表现**：模型从没见过这一类，不是「它学不会厚涂」。拿它当「画法的效应」证据，等同于拿「没见过的东西」证明「见过的另一类更容易」。

## 2. 四档实际混了三个维度

| 键 | 显示名 | 混着的事 |
|---|---|---|
| `flat` | 平涂/**Q版** | 画法（平涂）+ 比例（Q版）+ 用途（贴纸） |
| `paint` | 厚涂插画 | 画法（厚涂）+ 用途（插画） |
| `photo` | 实拍 | 成像方式 |
| `composite` | **图文**/**梗图** | 叠加层（有无文字）+ 用途（梗图） |

两处已经发生的错分（`docs/p0-change-list.md` 的聚类归档表）：

- 官方设定三视图（线稿 + 平涂）被归进 `paint`；
- 3D 渲染外景被归进 `flat`，唯一理由是「它是 Q 版」。

第二行说明：现在的分档实际按**形态**分，画法只是名字。

## 3. 要测的问题

两个假设都能解释 90 点的差距，现有数据无法区分：

- **H1 画法**：平涂比厚涂好认；
- **H2 构图**：单角色 + 干净背景比多人/场景/文字压图好认。

`洛天依4` 绝大多数是复杂构图，与 264 张的贴纸（单角色、纯色背景）同时差了两个维度。

## 4. 实验设计

工具在 `char-exp`（不进插件仓库）：

```
char-exp/tools/axis_probe_sample.py   # 分层抽样 + 生成标注页
char-exp/tools/axis_probe_run.py      # 本地复现训练 + 按格打分
```

1. **抽样**：按冻结骨干的 6 个簇 + `洛天依4` 分层抽 61 张，标注页 `char-exp/axis-probe/sheet.html`。
2. **标注**（人工，3 问/张）：画法（平涂 / 厚涂 / 难判断）、构图（单角色干净 / 复杂 / 难判断）、有无文字叠加。
3. **训练**：把 `洛天依4` 也放进训练集，探针所在批次整批（宽×高）划入评估集，避免同源虚高。
4. **判读**：按 2×2 格统计召回（阈值 0.6），比较两个轴的边际差距。

判据：某一轴的差距 ≥ 另一轴的 2 倍 → 该轴主导；两者接近 → 单轴不够，需要两轴或复合档；任一格不足 5 张 → 不可判读。

## 5. 在结论出来之前

- 报告文案不得把分档差异归因于「画法」；
- 标签文案只描述**看得见的东西**（平涂/厚涂 看笔触，干净/复杂 看画面），不暗示因果；
- 已知的 8 张官方三视图存在 `paint` 里，会拉低该档召回，属标签噪声，应在实验前批量改回 `flat`。

## 6. 第一轮结果（2026-10-21，61 张探针）

配置：264 正例 + 151 张 `洛天依4`（厚涂）+ 150 负例入库；探针 61 张按 (宽,高) 整批划入
评估集；训练 10 轮，train/val/test/eval = 275/59/59/168；测试集召回 1.00。

| 格 | n | 召回 |
|---|---:|---:|
| 平涂 / 干净 | 26 | 92% |
| 平涂 / 复杂 | 12 | 92% |
| 厚涂 / 干净 | 4 | 100%（样本不足） |
| 厚涂 / 复杂 | 8 | 100% |

同层对比（每对只变一个轴）：构图@平涂 **+1%**；画法@复杂 **−8%**（厚涂反而更高）。

**结论 1：「厚涂难认」不成立。** 把 151 张厚涂放进训练后，厚涂探针 100%、平涂 92% —— 方向与
0.5.8 的「厚涂 2%」相反。那 2% 是**分布外**，不是画法问题。

**结论 2：构图（干净 vs 复杂）在本实验里没有效应**（+1%）。单角色贴纸与多人场景得分相同。

**结论 3：文字叠加 −8 点**（有文字 90%，无文字 98%，n=20/41），量级远小于原来的 90 点假设。

### 失败样本只有 3 张，全都不是「画法」或「构图」问题

| 样本 | 分数 | 实际内容 |
|---|---:|---|
| p39 | 0.01 | 大字梗图（角色只占右侧 1/4） |
| p40 | 0.01 | 同类文字压图 |
| p41 | 0.06 | 灰阶线稿（无颜色） |

三者共同点是**角色本身的可辨识信息被削弱**（被文字挤占、或去色成线稿），而不是画法或构图。

### 一处必须更正的旧断言

0.5.11 写「cluster3 = 官方设定三视图（8 张）」，那是**看一张代表图得出的**。本轮抽到的 6 张
同簇样本里是文字梗图与灰阶线稿，没有一张是三视图。因此「8 张三视图误归 `paint`」这条
同样不成立，需要按实际内容重新核对。

### 本轮的效力边界

- 测试集召回 1.00、多数格 92–100% ⇒ **存在天花板效应**：只能排除 90 点量级的大效应，
  不能证明「没有效应」；
- `thick/clean` 只有 4 张，交互效应无法检验；
- 厚涂探针来自 `洛天依4`，与训练同源（只做了尺寸批次隔离）⇒ 100% 仍可能偏乐观；
- 每格 5 张的下限只够看量级差，不足以支撑「某档比某档好 8 个点」这种细结论。

## 7. 第二轮：修好模型后，结论反过来了（2026-10-21）

第一轮的比例是 275 正 : 100 负（2.75:1），模型学成了「像不像动漫梗图」：评估集 87.5% 的负例
被判成「是」，`balanced_accuracy` 只有 0.55。**那张召回表因此作废。**

按 0.5.8 验证过的比例重跑：**207 正例 + 128 张厚涂 + 800 负例**，探针集合不变，
train/val/test/eval = 667/142/142/255，训练 443 秒。

### 先看模型健不健康

| 集合 | balanced_accuracy | 负例误报 | 正例召回 |
|---|---:|---:|---:|
| test（随机划分） | **0.939** | 4.7% | 94.4% |
| eval（探针批次） | 0.698 | **37.5%** | 83.8% |

test 正常了，说明比例是主因。但 eval 的误报率仍有 37.5% —— 那些负例是「与探针同尺寸的其他角色
同人图」，属于真难点：模型对**别人画的动漫角色**仍然过于宽松。所以下面的召回数字仍然偏乐观。

### 分格结果

| 格 | n | 召回 |
|---|---:|---:|
| 平涂 / 干净 | 26 | 88%（23/26） |
| 平涂 / 复杂 | 12 | **67%（8/12）** |
| 厚涂 / 干净 | 4 | 75%（3/4，样本不足） |
| 厚涂 / 复杂 | 8 | 62%（5/8） |

同层对比：**构图@平涂 +22%**；**画法@复杂 +4%**。

### 结论：有方向性证据支持「构图」，但没有支持「画法」

- 画法（平涂 vs 厚涂）在同一构图下的差距只有 4 点 —— 与第一轮「厚涂不再更差」一致；
- 构图（单角色干净 vs 多人/场景）差 22 点，方向稳定（两类画法都是干净更高）。

**但这条证据还不够定案**：23/26 对 8/12 只是 4 张图的差别（Fisher 精确检验 p≈0.13），
`thick/clean` 只有 4 张，两个轴都存在，无法排除交互。
